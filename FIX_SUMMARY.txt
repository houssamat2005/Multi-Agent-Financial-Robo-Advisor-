PROBLÈME
════════════════════════════════════════════════════════════════════════════
❌ Le bouton "Créer un Portefeuille" ne marche QUE si l'utilisateur n'a 
   AUCUN portefeuille existant.
❌ Si l'utilisateur a déjà des portefeuilles, le clique sur "Créer" ne fait RIEN.

CAUSE RACINE
════════════════════════════════════════════════════════════════════════════
Le composant modal était défini SEULEMENT dans la branche:
  if (portfolios.length === 0) { return (...modal...) }

Quand portfolios.length > 0, cette branche n'est jamais atteinte
  → Main dashboard retourne sans modal
  → Bouton "Créer" (ligne 185) clique mais modal n'existe pas en DOM
  → Rien ne s'affiche à l'écran

SOLUTION APPLIQUÉE
════════════════════════════════════════════════════════════════════════════
✅ Placer le modal au niveau racine du composant
✅ Utiliser des Fragments <> pour envelopper les contenus
✅ Modal maintenant rendu dans TOUS les cas d'utilisation
