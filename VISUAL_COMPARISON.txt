DOUBLE RENDU (Non problématique)
════════════════════════════════════════════════════════════════════════════

Le modal est rendu à deux endroits:
  1. Dans la section "empty state" (si portfolios.length === 0)
  2. Au niveau racine du main dashboard (si portfolios.length > 0)

⚠️ Mais c'est SÛRE grâce au conditional rendering:
  - {showCreateModal && <Modal/>}
  - Seul un des deux sera affiché à la fois
  - L'autre condition n'est jamais atteinte (early return)

Analogy:
  if (x === 0) return <A>{showModal && <M/>}</A>
  // Si x === 0, on ne va JAMAIS à la ligne suivante
  return <B>{showModal && <M/>}</B>
  // Si x !== 0, on n'affiche que <M/> de B

Résultat: Une seule instance de modal rendue ✅
